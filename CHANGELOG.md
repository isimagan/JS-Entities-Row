# Changelog

All notable changes to JS Entities Row are documented in this file.

## v1.0.0

### Added

- First HACS-compatible release for the Home Assistant Entities card.
- JavaScript templates using triple brackets.
- Templated name, state, secondary information, icon, image, color and visibility.
- Tap, hold and double-tap actions, including multi-action sequences.
- Native Home Assistant entity icons, pictures, state formatting and theme variables.
